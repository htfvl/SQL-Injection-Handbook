# SQL-Injection-Handbook
В данном репозитории будет описана база по SQLi, также в будущем решение всех лабороторок на Port Swigger будут выложены в плейлисте на моем Youtube канале: https://www.youtube.com/@kuriyaaii
Личная база знаний по SQL Injection, SQL и эксплуатации SQLi.

Этот репозиторий создан на основе моих заметок из Obsidian и постепенно будет развиваться и дополняться.

Основной фокус:
- SQL theory
- SQL Injection
- detection methodology
- injection contexts
- data exfiltration
- auth bypass
- UNION-based attacks
- Blind SQLi

# Цель репозитория

Собрать структурированную базу знаний по SQL Injection:
- с понятными объяснениями;
- с примерами;
- с удобной структурой для повторения и изучения.
